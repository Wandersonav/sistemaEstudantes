Integração Google Calendar via MCP (Model Context Protocol)

Sincronização externa assíncrona entre o sistema de estudantes e sua agenda Google.

Status da Conexão MCP

  • Protocolo Model Context Protocol (MCP v1.0)
  • Servidor MCP @modelcontextprotocol/server-google-calendar
  • Sessões Sincronizadas 0 sessões
  • Comportamento de Rede Execução assíncrona com fallback local

Configuração (.agents/mcp_config.json)

{
  "mcpServers": {
    "google-calendar": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-google-calendar"],
      "env": { "GOOGLE_CALENDAR_ID": "primary" }
    }
  }
}
